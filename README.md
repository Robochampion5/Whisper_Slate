# Whisper Slate 🎤🏫

Whisper Slate is an entirely on-device, privacy-first classroom comprehension tool. It allows students to speak their doubts into their phones during a lecture (the "Red Light"), instantly transcribes and converts them into semantic meaning locally, and syncs them to a Teacher Dashboard (the "Green Light") that clusters the doubts in real-time.

**Zero audio ever leaves the student's device.** 

## Project Architecture

This is a monorepo consisting of three main parts:

1. **/student-app** (React + Vite + TypeScript PWA)
   - The student interface. Uses `@huggingface/transformers` to run `Xenova/whisper-tiny.en` for speech-to-text and `Xenova/all-MiniLM-L6-v2` for semantic embedding generation completely in the browser via WASM/WebGPU.
   - Built as a PWA to cache the models offline, ensuring robust operation even in poor campus Wi-Fi conditions.

2. **/server** (Python + FastAPI)
   - The local sync layer running on the teacher's laptop. 
   - Receives embedded doubt vectors (no PII, no audio).
   - Dynamically clusters similar doubts using `scikit-learn` `AgglomerativeClustering`.
   - Broadcasts real-time cluster state to the Teacher Dashboard via WebSockets.

3. **/teacher-app** (React + Vite + TypeScript)
   - The teacher dashboard. Displays live, clustered doubts grouped by meaning rather than verbatim text.
   - Includes real-time spike timelines using `recharts` to show momentum of confusion.
   - Displays anonymous connected devices with moderation capabilities (Kick/Block).

- Node.js (v18+)

## Quick Start Guide

### 1. Start the Sync Server (Python)
Navigate to the `server` directory, create a virtual environment, install dependencies, and run the FastAPI server:
```bash
cd server
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
*The server will run on http://localhost:8000*

### 2. Start the Teacher Dashboard
In a new terminal, navigate to the `teacher-app`:
```bash
cd teacher-app
npm install
npm run dev -- --port 5174
```
*Open http://localhost:5174 in your browser.*

### 3. Start the Student App
In another terminal, navigate to the `student-app`:
```bash
cd student-app
npm install
npm run dev -- --port 5173
```
*Open http://localhost:5173 in your browser (or use the QR code generated by the Teacher Dashboard to open it on your phone on the same Wi-Fi network).*

## Privacy & Security Guarantees
- **No Audio Uploads:** The Whisper STT model runs 100% locally in the browser via Transformers.js.
- **Anonymity:** Devices are tracked using ephemeral, hashed UUIDs for rate-limiting. No student names or emails are ever collected or sent to the dashboard.
- **Local Network Only:** The FastAPI server binds to the local IP, ensuring data never leaves the physical classroom environment.
